# CC Switch 便携版更新助手

## 直接使用
双击本目录的 **CCSwitch-Update-Helper.exe** → **检查更新** → 有新版时点击 **下载并更新**；同版本可点击 **重新安装 / 修复**。
无需安装 Python、Node.js 或额外 .NET SDK；使用本机已有的 .NET Framework 4.8。
工具必须放在 `cc-switch.exe`、`portable.ini` 旁边。文件夹名称不影响版本识别。
当前目录无需改名，你原来的快捷方式继续使用。

下载完成后会进行文件大小、官方 SHA-256、ZIP 结构、产品名称、程序版本和架构校验。
校验通过后会让你确认，再请求 CC Switch 正常退出；如果还在托盘，请右键托盘图标选择“退出”。
备份和替换期间不要重新启动 CC Switch。工具不强制结束进程。

## 安全与备份
- 仅原子替换 `cc-switch.exe`，不覆盖 `portable.ini`、Reasonix 或其他文件。
- 下载失败、校验失败、文件占用、备份失败时，不先删除原程序。
- 数据路径支持官方 app_paths.json 自定义目录、正常用户目录与旧版 HOME 回退；窗口显示备份来源。
- 数据备份位于 `%LOCALAPPDATA%\CCSwitchUpdateHelper\backups`，权限限定为当前用户、SYSTEM 和管理员。
- 备份包含旧程序、portable.ini、当前数据目录（包括数据库、WAL/SHM、设置、skills 等）。
- 不重复复制数据目录顶层的 `logs`、`backups`、`skill-backups`；超过 2 GB 则停止更新。
- 备份可能包含 API 密钥，请勿公开分享。助手不读取或上传配置内容；复制备份时只在本机操作。
- 不自动清理历史备份；你可通过“查看备份”打开后自行清理不再需要的版本。
- 新版本启动后可能迁移数据库，因此没有“一键降级数据”。需要恢复时阅读备份中的“恢复说明.txt”。
- 非官方辅助工具，未做代码签名。遇到 Windows/安全软件提醒请核对文件来源，不要关闭系统防护。

## 网络与限制
- 只访问官方 GitHub API 和官方发布附件服务器，使用 Windows 系统代理设置，不使用第三方镜像。
- 不需要 GitHub 账号或 Token；限流或网络失败时会显示原因。检查超时 45 秒，下载总时限 10 分钟。
- 官方未提供 SHA-256、变更便携包目录结构、架构不匹配时会停止，不猜测替换。
- 按 Windows 系统原生架构（不是现有 EXE 或助手进程位数）选择官方 x64 / ARM64 包。窗口显示系统、已装程序、下载目标三个架构；不一致会提示“修复为 x64 / arm64”。不支持 MSI、预发布版、降级覆盖、符号链接/目录联接安装路径。
- 不常驻、不添加开机启动、不创建计划任务。打开助手后手动点击检查更新。
- 当前已是最新稳定版时，按钮显示“重新安装 / 修复”，允许重新下载官方包覆盖同版本。仍需退出确认、备份和校验。
- 日志与临时下载位于程序旁边 `update-helper-data`；正常结束会清理本次临时下载。
- 若断电/强制退出：先不要启动或降级程序，保留备份；根据备份中的新旧 SHA256 判断原子替换是否完成。

## 源码与重新编译
源码位于 `update-helper\src`。不依赖 NuGet，可用 Windows 内置编译器重建：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\update-helper\build.ps1 -Test
```

测试使用临时目录，不更新现用程序。受限沙箱中 Windows ACL 测试可能被阻止；正常用户环境无需管理员权限。
