- 29 项核心测试、11 项 Markdown 测试、6 项架构场景、6 项启动/渲染场景通过。
- 布局回归涵盖默认窗口、最小窗口、长路径和长错误提示；实际 144 DPI 和虚拟化 96 DPI 上下文，另有 125% / 200% 字号/尺寸模拟。

- 未执行实际 CC Switch 安装、退出或数据库恢复；未进行 ARM64 实机或跨显示器 DPI 验证。
